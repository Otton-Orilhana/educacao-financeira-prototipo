# educacao-financeira-prototipo
Protótipo funcional de uma plataforma de educação financeira para alunos do ensino fundamental e médio. Desenvolvido em HTML, CSS e JavaScript. Backend em Python + SQL planejado, mas não implementado nesta versão.


##  Sobre o Projeto

Este repositório contém o **protótipo funcional** de uma plataforma digital de educação financeira e empreendedorismo, desenvolvida para alunos do ensino fundamental e médio.  
O objetivo é oferecer conteúdos acessíveis, trilhas de aprendizagem, quizzes interativos e atividades reflexivas, utilizando uma interface web simples, responsiva e intuitiva.

Este protótipo foi desenvolvido como parte de um projeto acadêmico.  
A interface foi concluída integralmente, enquanto o backend em Python + PostgreSQL/MySQL foi **planejado**, mas **não implementado nesta versão**, devido ao tempo disponível.

---

##  Objetivos do Protótipo

- Disponibilizar conteúdos de educação financeira de forma acessível e interativa.  
- Estimular o pensamento empreendedor entre jovens.  
- Criar trilhas de aprendizado com exemplos práticos e linguagem simples.  
- Implementar quizzes avaliativos para reforçar o aprendizado.  
- Simular o progresso do usuário utilizando `localStorage`, representando o comportamento futuro do banco de dados.  
- Validar a experiência do usuário e a arquitetura da plataforma antes da implementação do backend.

##  Tecnologias Utilizadas

### **Frontend (implementado no protótipo)**  
- HTML5  
- CSS3

### **Backend (planejado, mas não implementado nesta versão)**

##  Funcionalidades Implementadas

###  Trilhas de Aprendizagem  
7 trilhas completas com conteúdos sobre:

- Fundamentos da educação financeira  
- Controle de gastos  
- Bancos e serviços financeiros  
- Crédito e endividamento  
- Poupança e investimentos  
- Empreendedorismo  
- Psicologia financeira  

###  Quizzes Interativos  
Cada trilha possui um quiz com:

- 10 perguntas de múltipla escolha  
- Correção automática  
- Exibição de pontuação  
- Registro de conclusão via `localStorage`

###  Sistema de Progresso  
O protótipo inclui:

- Registro de trilhas concluídas  
- Registro de quizzes concluídos  
- Destaque visual (verde para trilhas, azul para quizzes)  
- Simulação de banco de dados usando `localStorage`  
- Atualização automática da interface

###  Atividades Reflexivas  
A Trilha 7 possui um formulário completo para reflexões pessoais, também salvo via `localStorage`.

---

##  Funcionalidades Planejadas (não implementadas no protótipo)

O backend em Python + SQL estava previsto na metodologia, mas não foi implementado nesta versão.  
As seguintes funcionalidades permanecem como **trabalho futuro**:

- Cadastro e login de usuários  
- Armazenamento real do progresso no banco de dados  
- Registro de respostas dos quizzes  
- Dashboard administrativo  
- API REST para comunicação com o frontend  
- Migração do `localStorage` para PostgreSQL/MySQL  
- Sistema de autenticação e perfis de aluno

A ausência dessas etapas **não compromete o objetivo do protótipo**, que é validar a interface e a experiência do usuário.
